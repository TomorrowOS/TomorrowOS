# TomorrowOS Roadmap

TomorrowOS is an open source unified API layer for digital signage operating systems.

This roadmap outlines the intended direction of the project. It may change as the project develops, contributors provide feedback, and real-world testing reveals platform-specific limitations.

## Roadmap principles

TomorrowOS should remain:

- Simple for developers
- Honest about operating system limitations
- Safe for device control
- Useful for real signage deployments
- Open enough for the industry to build on
- Careful with security, package handling and customer environments
- Focused on reliability, fallback behaviour and capability evidence

# TomorrowOS Public Roadmap

Our mission is to create an open-source application and runtime foundation for digital signage hardware, allowing developers to build once and deploy across supported platforms.

## Shipped
- Open-source Server SDK and self-hosted CMS starter
- Samsung Tizen, BrightSign and Windows players
- Device pairing, playback policies and content delivery
- Offline caching and recovery
- Device capabilities, control commands and telemetry
- Screen tags, references and conditional content scheduling
- Developer guides and platform certification framework

## Building now
- Next-generation TomorrowOS Application Runtime
- HTML5 application SDK and manifest-based app loading
- Runtime API improvements and compatibility testing
- NovaStar Android-based device integration and validation
- Expanded developer examples and certification coverage

## Next
- Public third-party application examples
- Expanded application and widget development documentation
- More hardware models and verified firmware combinations
- Improvements to runtime deployment and update workflows
- Broader community contribution and certification tooling

## Exploring
- LG webOS support
- Broader Android hardware compatibility
- OEM integrations and alternative hardware platforms
- Advanced synchronisation and playback capabilities
- Future ecosystem and tooling opportunities

Roadmap items are indicative, not delivery commitments. Features are considered supported only after appropriate implementation and testing.

## Long-term vision

The long-term vision is for TomorrowOS to become a trusted open source operating layer for digital signage.

A layer that helps developers, integrators, CMS vendors and hardware partners build better signage software across many operating systems while staying honest about what each platform can actually support.

The goal is not to hide complexity.

The goal is to make complexity easier to manage.
